PART 1 — CUSTOMER ISOLATION
==================================================

Use Customer A's authenticated session.

A1. Verify Customer A can access its own profile.

A2. Verify Customer A can access its own address.

A3. Attempt to access Customer B's address using Customer B's address ID.

Expected:
- access denied / not found according to existing API semantics
- no Customer B data returned

A4. Attempt to manipulate any customer-owned object ID available through the existing customer API by replacing Customer A's ID with Customer B's ID.

Expected:
- ownership remains derived from authenticated Customer A
- Customer B data is not returned
- no unauthorized modification occurs

Repeat equivalent tests with Customer B attempting to access Customer A's address/profile-owned data.

IMPORTANT:
Do not create or modify any records merely to perform these tests.
