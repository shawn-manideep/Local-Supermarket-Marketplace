REPLIT PROMPT — Vendor Store Location + Admin Vendor Creation
Objective
Enhance the existing Vendor Profile and Admin Portal with two related capabilities:
1. Add complete physical store location details to the existing Vendor/Store Profile.
2. Allow an Admin to create and provision new Vendor accounts directly from the Admin Portal.
The existing application architecture, authentication, Master Catalog, vendor product ownership, customer shopping, cart, orders, stock, delivery partner workflow, and historical order data must remain intact.
Do not redesign or replace the existing Vendor architecture. Extend it safely.
PART 1 — FIX THE CURRENT VENDOR PROFILE
Current Problem
The existing Vendor Profile does not contain sufficient physical store location information.
A vendor represents an actual supermarket/store, so the platform needs to know where that store is located.
The location information must be associated with the vendor/store, not with individual products.

Extend the existing Vendor/Store profile with:

Location Ownership
The location belongs to the Vendor/Store profile.
Do NOT add location fields to:
- Master Products
- Vendor Products
- Product Variants
- Orders as mutable vendor profile data
Orders must continue to preserve their existing historical snapshots.
If the current order architecture already stores an appropriate delivery/store address snapshot, do not replace or modify that mechanism unnecessarily.

IMPORTANT PRODUCT OWNERSHIP RULE
Adding a Vendor through Admin must NOT automatically add products to that Vendor.
After the Vendor account is created:
Admin creates Vendor
        ↓
Vendor Store exists
        ↓
Vendor logs into Vendor Portal
        ↓
Vendor opens Master Catalog
        ↓
Vendor selects products
        ↓
Selected products become that Vendor's store listings

Vendor A and Vendor B remain completely independent.
For example:
Master Catalog
     │
     ├── Basmati Rice
     ├── Sugar
     └── Cooking Oil
     
     ↓

Vendor A
 ├── Basmati Rice
 └── Sugar

Vendor B
 ├── Sugar
 └── Cooking Oil

Vendor A selecting Basmati Rice must never automatically add it to Vendor B.
IMPORTANT COMMERCIAL DATA RULE
Creating or editing a Vendor profile must never modify:
- Vendor product price
- Stock
- Available quantity
- Selling unit
- Pack configuration
- Vendor-specific variants
- SKU/external codes
- Promotions
- Orders
These remain vendor-owned.
