4. VENDOR — PRODUCT IMAGE INPUT
==================================================

CURRENT PROBLEM:

When a Vendor creates a product that is not available in the Master Catalog, the product creation form currently requires an Image URL.

The Vendor should have two options:

1. Image URL
2. Upload Image

The Vendor should be able to use either option.

--------------------------------------------------
4.1 Image input UI
--------------------------------------------------

In the Vendor Add Product form, replace the current image URL-only experience with something like:

Product Image

[ Image URL ] [ Upload Image ]

OR provide a clear two-option layout:

Image URL
[____________________________]

OR

Upload Image
[ Choose Image ]

The exact UI should match the existing design system.

--------------------------------------------------
4.2 Image URL
--------------------------------------------------

If Vendor chooses Image URL:

- Allow a valid image URL.
- Validate the URL.
- Show an image preview when possible.
- Do not download/store the image unnecessarily if the existing architecture already supports external image URLs safely.

Use the existing product image field/model.

--------------------------------------------------
4.3 Image Upload
--------------------------------------------------

If Vendor chooses Upload Image:

Allow the Vendor to select an image from their device.

Use the project's existing storage infrastructure if available.

Do NOT create a second storage system if one already exists.

If the current project already has Supabase Storage or another application storage mechanism, reuse it.

--------------------------------------------------
4.4 Supported image types
--------------------------------------------------

At minimum support:

- JPG/JPEG
- PNG
- WebP

Validate:

- MIME type
- file extension
- reasonable file size

Reject unsupported or unsafe file types.

Do not allow executable files.

--------------------------------------------------
4.5 Image preview
--------------------------------------------------

After selecting/uploading an image:

Show a preview before saving the product.

Example:

Product Image

[ IMAGE PREVIEW ]

[ Replace Image ]

The Vendor should be able to replace the selected image before submitting the product.

--------------------------------------------------
4.6 URL OR Upload — exactly one source
--------------------------------------------------

A product should use one image source at a time.

Rules:

If Image URL is selected:
→ save URL

If Image Upload is selected:
→ upload file and save resulting storage reference

If both are provided:
→ require the Vendor to choose which one to use OR clearly make one source active.

Do NOT silently store two conflicting primary images.

--------------------------------------------------
4.7 Editing an existing Vendor product
--------------------------------------------------

If the existing Vendor product edit screen supports product images, provide the same:

- Image URL
- Upload Image
- Preview
- Replace

behavior there as well.

Do not change unrelated product fields.
