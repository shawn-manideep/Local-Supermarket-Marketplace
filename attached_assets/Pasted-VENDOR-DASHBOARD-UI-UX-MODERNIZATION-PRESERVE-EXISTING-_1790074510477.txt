==================================================
PART 1 — OBJECTIVE
==================================================

The current Vendor Dashboard is functional, but it currently feels too much like an internal developer/database management screen.

Redesign it into a professional, modern supermarket/vendor management dashboard suitable for a real supermarket owner.

The Vendor should immediately understand:

1. How is my store doing?
2. Are there new orders?
3. Which orders require action?
4. What products/categories do I manage?
5. What is my store status?
6. What delivery/order actions do I need to perform?

The result should feel like a polished business application, not a developer prototype.

Use modern grocery/retail management UX patterns for inspiration.

Do NOT copy any third-party branding, logos, colors, proprietary layouts, assets, or designs.

- show useful success feedback

- retain the actual server status
- do not show a false success state
