=================================================
PROJECT CONTEXT
=================================================

The project is the existing Local Supermarket Marketplace.

The previous READ-ONLY architecture audit confirmed:

- Customer authentication currently uses Supabase email/password.
- Dashboard authentication currently uses Supabase email/password.
- Supabase owns passwords, sessions, access tokens and refresh tokens.
- `user_profiles.id` references `auth.users.id`.
- Customer identity is linked to the Supabase Auth UUID.
- Vendor store ownership uses `stores.owner_user_id`.
- Current roles are:
  - customer
  - vendor
  - admin
- There is currently no public vendor registration workflow.
- There is currently no username field or username lookup layer.
- There is currently no username/password login flow.
- There is currently no forgot-password UI/API flow.
- There is currently no Delivery Partner role.
- Existing customer/vendor/order/store functionality must be preserved.

Previous audit also established that existing Auth UUIDs and Supabase-managed credentials must NOT be replaced unnecessarily.
