GOAL

Convert the current Replit preview setup from the mixed artifact/legacy architecture into one consistent artifact-managed preview architecture.

The Stage 9B audit established that:

1. Replit artifact-managed routing currently owns:
   /api
   /__mockup

2. No artifact currently owns:
   /
   /dashboard
   /customer

3. The real Phase 12 backend runs separately on port 5000.
4. Dashboard runs separately on 5173.
5. Customer Web runs separately on 8082.
6. Legacy workflows were added for these services, but those workflows do not become owners of the artifact-managed public domain.
7. Therefore the shared preview domain returns 404 at / and external port attempts can return 502.
