7. REORDER / REPEAT ORDER AUDIT
=======================================================

NEW CUSTOMER REQUIREMENT:

After login, the customer should see "Re-order" rather than the current "Orders" concept where appropriate.

Reorder means:

- customer views a previous order
- selects Repeat/Re-order
- eligible previous items are added to a NEW/current cart
- customer can continue shopping
- customer can Add More Items
- customer reviews cart
- customer checks out normally

Reorder must NOT immediately place an order.

When repeating an old order:

- use current product/variant availability
- use current prices
- use current stock
- do not alter historical order data
- unavailable items must be clearly identified
- no automatic substitutions
- if the previous store is inactive or no longer serves the customer's pincode, reorder should be blocked with an explanation
- if another store is already in the active cart, use the existing store-switch confirmation logic

AUDIT whether any reorder implementation currently exists.

If not, identify the required backend and frontend changes.

DO NOT implement.
