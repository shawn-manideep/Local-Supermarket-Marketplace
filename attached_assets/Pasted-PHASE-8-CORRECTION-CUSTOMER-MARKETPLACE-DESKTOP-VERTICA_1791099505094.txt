PHASE 8 CORRECTION — CUSTOMER MARKETPLACE DESKTOP VERTICAL SCROLLING

ISSUE FOUND DURING MANUAL BROWSER ACCEPTANCE:

The Customer Marketplace/Home product listing is NOT vertically scrollable at the normal desktop browser window size.

Observed behavior:

- Product cards continue below the visible viewport.
- The page does not provide normal vertical scrolling.
- The lower products cannot be reached at the current desktop window size.
- If the browser/window is minimized or the viewport becomes smaller, the layout changes and additional products become accessible.
- This indicates an incorrect height/overflow/flex layout in the Customer application.

This is a Phase 8 acceptance blocker.

--------------------------------------------------

Fix the Customer Marketplace so that the customer can normally scroll through the complete page/product list at:

- desktop width
- desktop height
- tablet width
- mobile width

The user must NOT need to resize/minimize the browser to access products.
