# PHASE 1 — REPOSITORY + PROJECT FOUNDATION ONLY

## Project

Local Supermarket Marketplace

## Phase

Phase 1 — Repository + Project Foundation

## Important

This is a new project and there is currently no existing application code to inspect.

For this Phase 1 only, you may create the initial project structure from scratch.

For every future phase after Phase 1, you MUST inspect the existing codebase before making any changes.

---

# OBJECTIVE

Set up ONLY the repository and project foundation.

This phase must produce:

* the monorepo structure
* the customer Expo starter app
* the vendor/admin React web starter app
* the Node/Express/TypeScript backend skeleton
* the backend `/health` endpoint
* empty shared packages ready for future phases
* documentation placeholders

This phase must NOT implement the actual marketplace.

---
