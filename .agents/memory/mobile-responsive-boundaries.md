---
name: Mobile responsive boundaries
description: Product scope and acceptance constraints for mobile layout work across all marketplace portals.
---

Customer, Vendor, Delivery Partner and Admin must remain usable at 320, 360, 375, 390 and 414px, with existing desktop/tablet behavior retained. Use the existing applications, themes and navigation destinations, not a separate mobile app or a visual redesign.

**Why:** The user explicitly requested all-portal mobile responsiveness while preserving commerce, account, delivery, document and catalog behavior.

**How to apply:** Treat responsive changes as presentation work; preserve existing business rules and Customer scrolling boundaries. Prefer labeled mobile cards for ordinary tables and localized scrolling only for genuinely wide comparisons/history. A source check or signed-out screenshot is not proof of authenticated interactive acceptance; report pending device/layout checks explicitly.
